# Каталог приложений cveloy102

Здесь собраны мои приложения для Android, Windows и macOS, а также панель для собственного сервера. В каталоге можно выбрать систему, посмотреть интерфейс и перейти к установке.

**[Открыть каталог приложений](https://cveloy102.github.io/)**

## Что вы хотите сделать?

| Задача | Приложение и инструкция |
| --- | --- |
| Передать файлы между устройствами в одной сети | [DROP](https://github.com/cveloy102/hl100-drop#начало-работы) |
| Увидеть заряд Xiaomi Buds 5 при открытии кейса | [Xiaomi Buds 5 Overlay для Android](https://github.com/cveloy102/buds-curtain#начало-работы) |
| Управлять компьютером с телефона | [Пульт для Android и Windows](https://github.com/cveloy102/pult#первый-запуск) |
| Включать свой VPN при выходе из дома | [AutoTurn для Android](https://github.com/cveloy102/autoturn-vpn#как-начать) · [AutoTurn для macOS](https://github.com/cveloy102/autoturn-macos#установка-за-несколько-шагов) |
| Направить через VPN выбранные сайты на Windows | [RED_ROUTE](https://github.com/cveloy102/RED_ROUTE#первый-запуск) |
| Записать задачу и получить напоминание | [СВАЛКА для Android и Windows](https://github.com/cveloy102/reminder#начало-работы) |
| Сохранить видео или аудио на Windows | [PULL](https://github.com/cveloy102/pull-video-downloader#начало-работы) |
| Повторить движение мыши на Windows | [Robot Loop](https://github.com/cveloy102/robot-loop#первый-запуск) |
| Управлять доступом к своему Telegram WEB Proxy | [Relay Panel для Ubuntu](https://github.com/cveloy102/telegram-webproxy-panel#первый-запуск) |

На странице каждого проекта указаны требования и первый шаг. Описание изменений и файлы предыдущих версий находятся в разделе **Releases** этого проекта.
